ENDPOINTS:
==========
GET  /                           → Frontend app
GET  /cms-admin                  → CMS admin panel
GET  /api/content                → List all content
GET  /api/organizations          → Organizations
GET  /api/initiatives            → Initiatives
GET  /api/goals                  → Goals
GET  /api/performance            → Performance data
GET  /api/templates              → Templates list
GET  /api/templates/:name        → Get template
POST /api/templates              → Save template
GET  /api/notes                  → Notes list
POST /api/notes                  → Create note
PUT  /api/notes/:id              → Update note
DELETE /api/notes/:id            → Delete note
GET  /api/sections               → Sections list
POST /api/sections               → Create section

GET  /api/content-tags           → Content tags

PUT  /api/content-tags/:id       → Update tag
DELETE /api/content-tags/:id     → Delete tag
