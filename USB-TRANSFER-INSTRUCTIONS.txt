STEP 1: COPY TO TARGET PC
  • Copy ZIP file to USB drive
  • Transfer to target PC (e.g., C:\ExecSummary\)
  • Extract ZIP file
  • You'll get folder: ExecSummary-Production-USB-Transfer/

STEP 2: INSTALL NODE.JS (if not installed)
  • Visit: https://nodejs.org/
  • Download: LTS version (v20.x or v22.x)
  • Install with default settings
  • Restart computer after installation

STEP 3: RUN APPLICATION
  • Open folder: ExecSummary-Production-USB-Transfer/
  • Double-click: START-SERVER.bat
  • Wait for "Server running" message
  • Browser opens automatically!
