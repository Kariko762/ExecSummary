💾 API ENDPOINTS
───────────────────────────────────────────────────────────────
CORE:
  GET  /api/health                   Server health check
  GET  /api/summaries                List all summaries
  GET  /api/summaries/:id            Get summary by ID
  POST /api/summaries                Create new summary
  PUT  /api/summaries/:id            Update summary
  DELETE /api/summaries/:id          Delete summary

TEMPLATES:
  GET  /api/templates                List templates
  GET  /api/templates/:name          Get template
  POST /api/templates                Create template
  PUT  /api/templates/:name          Update template

DATA ENGINE:
  GET  /api/data-engine/query/:source  Query data source
    Query Parameters:
      range          Single date range
      range1, range2 Two periods for comparison
      field          Field to aggregate (default: hours)
      categories     Comma-separated category filter
      operation      Aggregation type (sum, count)

CONTENT TAGGING:
  GET  /api/content-tags             List all tags
  POST /api/content-tags             Create tag
  GET  /api/summaries/:id/tags       Get tags for summary
  PUT  /api/summaries/:id/tags       Update tags

🎯 EXPRESSION LANGUAGE
───────────────────────────────────────────────────────────────

{{data:path.to.field}}              Access content data
{{config:setting}}                  Access configuration

EXAMPLE:
